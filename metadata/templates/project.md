# Project title

Template only. Create `user_data/projects/<project_name>/README.md` when a stated
goal benefits from coordinating several artifacts or ongoing work. Omit unused
sections and placeholders. Resolve links relative to that project directory.

## Goal and scope

Describe the learner's stated objective, intended result, and relevant boundaries.
Link the journal entry establishing it. Distinguish proposals from accepted goals.

## Status

Record current status (for example, active, paused, or completed), the date, and
supporting evidence. Describe what completion means for this project. Completion
is not evidence of mastery; link topic notes for actual learner observations.

## Knowledge

Link relevant topic notes, which own explanations, learner evidence, and learning
questions. A project can cross subjects; a topic can support several projects.

## Artifacts

Link each relevant artifact bundle's README and describe its role. Keep editable
sources and outputs in their canonical bundles under `user_data/artifacts/`.
Link shared artifacts rather than copying or moving them into this directory.

## Decisions and constraints

Summarize current decisions and constraints with dated journal links. Keep the
chronological history in the journal rather than duplicating it here.

## Continue here

Record the exact stopping point, unfinished work, required inputs, blockers, and
the next action. Label suggested actions separately from user commitments. Include
enough links and context for another agent to resume without the previous chat.
This section resumes the project; it does not replace the latest lesson checkpoint.
