A useful record preserves questions, attempts, assistance, and corrections. It separates a correct explanation from evidence of your understanding.

No required syllabus

Go deep. Switch topics.
Return whenever you like.

Explore an idea today and something unrelated tomorrow. Retrieve prior learning when it helps. A saved unfinished question is a place to return, not an obligation.

Courses, quizzes, reviews, and projects can help when you want them. None is a required entrance to an ordinary question.

The protocol preserves flexibility; teaching methods are implementation choices.

Useful beyond the chat

Save diagrams, experiments, code, and slide decks with their context and editable sources. Projects can connect several outputs without duplicating them.

A finished artifact is not proof of understanding. Preserve what the learner actually did alongside what the agent generated.

Ordinary files · portable links · optional project organization.
