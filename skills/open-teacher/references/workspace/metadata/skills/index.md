# Teaching skills

This reusable catalog is shared across learners and agents. Read a skill's complete
`SKILL.md` when relevant. No native registration or slash command is required.

| Skill | When useful |
| --- | --- |
| [Teach with visuals](teach-with-visuals/SKILL.md) | A diagram, plot, or interactive experiment clarifies a relationship or supports a prediction. |

Personal outcomes belong in `user_data/memory/teaching_methods.md`, with links to
that learner's journal; paths here refer to the workspace root. Using a skill does
not prove its effectiveness. Propose generalized improvements based on evidence
and update skills when authorized. Keep personal examples and preferences in user data.
