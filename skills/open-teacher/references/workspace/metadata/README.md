# Reusable teaching metadata

- [Open Teacher Protocol](../PROTOCOL.md): draft 0.1 behavioral contract.
- [Teacher instructions](teacher_instructions.md): shared behavior, recording,
  retrieval, startup, and knowledge-format conventions.
- [Skill catalog](skills/index.md): reusable teaching methods.
- [Record templates](templates/): optional shapes for notes and artifacts.
- [Project template](templates/project.md): optional coordination across artifacts and topics.
- [Blank user-data skeleton](templates/initial_user_data/): neutral startup records.
- [Memory handoff checks](checks/memory_handoff.md): fresh-session recall and
  evidence-boundary checks after memory changes.

Reuse this directory with `PROTOCOL.md`, the root agent entry points, and project
documentation in a fresh workspace. All workspace paths inside the instructions
resolve from that root. Templates are authoring aids, not evidence about a learner.

Keep names, personal goals, lesson histories, assessments, artifacts, and observed
teaching outcomes in that workspace's `user_data/`. Improve reusable methods only
with generalized guidance and appropriate authorization. Keep this directory usable
when no existing learner data is present.
