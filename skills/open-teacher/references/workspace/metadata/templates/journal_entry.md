# Journal entry template

Copy only the sections that add useful information into the appropriate monthly
journal. Replace placeholders; use a unique dated heading. This template is not a
record of learning. Use relative links from the destination file.

## YYYY-MM-DD — NN — Topic

**Context:** What question, goal, or exercise led to this checkpoint?

**What happened:** Briefly capture the useful explanation, activity, or change.
If a teaching skill was used, link it and note any observed benefit or difficulty;
using a skill alone does not establish that it was effective.

**Learning evidence:** What did the learner actually say or do? Distinguish
self-report, independent work, hints, and teacher-generated material. If nothing
was assessed, say so. Preserve enough detail to support future interpretation.

**Unresolved:** What remains uncertain or unfinished?

**Records and artifacts:** Link to the canonical topic note and existing materials.
State any incomplete saves or unverified results.

**Continuation:** What would be useful next, and why? Omit if no continuation is needed.
For unfinished work, preserve the exercise, necessary inputs, and assistance already
given, or link to a saved artifact containing them. Another agent must be able to
resume even if the corresponding topic update was interrupted.
