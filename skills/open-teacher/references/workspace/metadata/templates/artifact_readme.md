# Artifact title

Template only. Create a README in each substantial artifact bundle and include
only applicable sections. Resolve links relative to the bundle.

## Learning purpose

The question or objective this material addresses. Link the related knowledge note
and journal entry. Describe what this artifact helps explore.
Link related project READMEs when applicable; an artifact may support several
projects or none. Keep the files in this canonical bundle rather than duplicating them.

## Contents and provenance

List useful files and identify editable sources, exports, inputs, and results.
Describe who produced the material: learner, teacher, collaboration, or external
source. Cite external origins. Separate a learner attempt from a supplied solution.

## Open or run

Explain how to view or execute the material, with the working directory and required
inputs. For code, document the tested runtime and exact dependency versions when
needed, preferably in a local dependency file. Keep environments and caches out of
the bundle. For external datasets, record source and retrieval details.

## Verification and limitations

State what was actually checked, when, and the observed result. Mark unexecuted
code, uninspected exports, or unfinished work explicitly. Explain how useful outputs
can be regenerated. Artifact correctness is separate from learner understanding.
