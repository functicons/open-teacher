# Project artwork

Editable SVG illustrations:

- `open_teacher_banner.svg`: “Any agent. Any topic. Your learning, remembered.”
  Codex and Claude Code connected to shared learning
  memory containing learner context, knowledge, dated logs, optional projects,
  and artifacts. The projects-to-artifacts connection shows grouping, not a
  required course sequence. Blue, red, white, and gray palette.
- `why_open_teacher.svg`: five learning problems paired with the design choices
  they motivate. The complete text comparison is also in `docs/overview.md`.
- `learning_flow.svg`: ask a question, save useful context, continue across chats.

These were authored directly as SVG on 2026-09-19, without image generation.
They contain editable text and shapes, descriptive titles, and accessible
summaries. They have no scripts, external fonts, or remote image dependencies.
Terminal icons are generic symbols, not official provider logos. Naming an agent
is an example of intended use, not an endorsement or interoperability certification.

The previous `open_teacher_banner.png` remains available as earlier generated
artwork. Its generation prompt is preserved in `raster_banner_prompt.md`.
